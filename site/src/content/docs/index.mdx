:::caution[There is no download yet]
Hearth has never been released. There is no installer to download and no
signed binary anywhere: `release/trust.json` points at
`releases.hearth.invalid`, a reserved name that cannot resolve, because an
updater aimed at a real host nobody controls is worse than one aimed at a
host that cannot exist.

Building it yourself takes about twenty minutes, most of it waiting.
[The install page](/hearth-windows/getting-started/install/) walks through it
from an empty folder.
:::

## What it is

<CardGrid>
  <Card title="It brings its own engine" icon="rocket">
    The installer carries a pinned CPython and llama.cpp's `llama-server`.
    Nothing to install first, and no Ollama required. It borrows the WebView2
    runtime Windows already ships rather than bundling a second browser.
  </Card>
  <Card title="It asks before it acts" icon="approve-check">
    Four permission modes. The default reads freely and stops before every
    file write and every shell command. Underneath, each run carries a fixed
    list of tools it may touch at all, enforced even in bypass mode.
  </Card>
  <Card title="It knows what fits" icon="setting">
    The model shop measures your RAM and VRAM and computes whether a given
    quantisation actually fits, KV cache included, rather than recommending
    something that will swap to disk and feel broken.
  </Card>
  <Card title="It stays inside the folder" icon="warning">
    Every file tool passes a containment check: path traversal, absolute
    paths, reserved device names, alternate data streams and NTFS junctions
    are all rejected, so a confused agent cannot reach outside the directory
    you named.
  </Card>
</CardGrid>

:::note[Two projects, one name]
This is Hearth for Windows: a desktop application, Apache-2.0, in
[its own repository](https://github.com/EricFinland/hearth-windows).

There is also [hearth](https://ericfinland.github.io/hearth/), a security-first
NixOS system for running local LLMs and sandboxed agents. Same name, same
author, different thing. That one is orange and this one is blue, which is
the fastest way to tell which set of docs you are reading.
:::
