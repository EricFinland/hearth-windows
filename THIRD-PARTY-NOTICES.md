## Copyleft components, and what they oblige

Two components of the Electron runtime are licensed under the GNU
Lesser General Public License. Neither is combined with Hearth's own
code at the source level: Hearth is Python and JavaScript running on
top of a runtime it did not build, and the LGPL applies to that
runtime, not to the application. Redistributing it still carries
obligations, and they are met as follows.

### FFmpeg

- **Licence.** LGPL-2.1-or-later.
- **Where.** `ffmpeg.dll`.
- **Evidence.** Electron ships a build configured without --enable-gpl, so the GPL parts of FFmpeg are absent and LGPL-2.1-or-later applies. The full LGPL-2.1 text is inside LICENSES.chromium.html under the ffmpeg entry.

### Blink, derived from WebKit and KHTML

- **Licence.** LGPL-2.0-or-later and LGPL-2.1-or-later in part, BSD-3-Clause for the rest.
- **Where.** `Hearth.exe (statically linked)`.
- **Evidence.** the WebKit entry in LICENSES.chromium.html carries the full GNU Library General Public License version 2 and the full GNU Lesser General Public License version 2.1.

Obligations, and how each is discharged:

1. **Notice that the library is used.** This file, shipped inside the
   application.
2. **A copy of the licence.** The complete GNU Lesser General Public
   License version 2.1 and GNU Library General Public License version 2
   texts ship at the application root in `LICENSES.chromium.html`,
   under the `ffmpeg` and `WebKit` entries.
3. **The corresponding source.** Both components are built from public
   sources at a version this file names. Electron 43.2.0
   is published at <https://github.com/electron/electron>, and its
   Chromium revision, including the FFmpeg and Blink trees, is
   reachable from that tag. Anyone entitled to the source under the
   LGPL may also request it through the contact route in SECURITY.md
   and it will be provided.
4. **The right to relink against a modified library.** `ffmpeg.dll` is
   a separate dynamic library in the install directory. Replacing it
   with a compatible build requires no cooperation from Hearth, which
   is what section 6 of the LGPL asks for. Blink is statically linked
   into the Electron executable; the remedy there is the same one
   every Chromium-derived product relies on, which is that the
   complete source of that executable is public and rebuildable.
